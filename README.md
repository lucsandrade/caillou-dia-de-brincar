# 🎈 Caillou: Dia de Brincar!
https://caillou-dia-de-brincar.ai.studio/](https://caillou-dia-de-brincar.ai.studio/

Coletânea interativa de 14 minijogos educativos em português do Brasil (pt-BR), desenvolvida especialmente para crianças de 3 anos com interface responsiva para dispositivos móveis, ilustrações vetoriais em SVG e narração/efeitos sonoros integrados.

> *Interactive toddler-friendly educational web game collection in Brazilian Portuguese (pt-BR) featuring 14 mini-games, custom 2D SVG illustrations, Web Audio API sound effects, and Gemini TTS / Web Speech voice narration — built using React, TypeScript, and Google AI Studio.*

## 🎮 Funcionalidades / Features
- **14 Minijogos Interativos:** Guardar os Brinquedos (Formas), Lanche das Cores, Esconde-Esconde + Bolhas, Quebra-Cabeça de 4 Peças, Som dos Animais, Jogo da Memória, Xilofone Musical, Pintar a Borboleta e Vestir o Caillou.
- **Mobile-First & Touch Friendly:** Layout responsivo (`100dvh`) otimizado para telas de toque em smartphones e tablets, com suporte a instalação como **PWA**.
- **Áudio e Narração Infantil:** Efeitos sonoros sintetizados via **Web Audio API** e narração amigável em pt-BR via **Gemini TTS / Web Speech API**.

## 🛠️ Stack Tecnológica / Tech Stack
- **Frontend:** React, TypeScript, Tailwind CSS, SVG / Canvas
- **AI & Audio:** Google AI Studio (Gemini), Gemini TTS / Web Speech API, Web Audio API
- **Deploy:** Google Cloud Run / AI Studio Hosting
